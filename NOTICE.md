# Third-party software

This repository is derived from the open-source
[EasyEdit](https://github.com/zjunlp/EasyEdit) framework and preserves its
MIT license.

It includes integrations of ROME, MEMIT, AlphaEdit, UnKE, UniKE,
Multi-MELO, LoRA, AdaLoRA, RoseLoRA, CorDA, and LoRA-Null. The original
papers, repositories, and licenses remain the authoritative sources for
these methods.

KSpace-specific code is located under `easyeditor/models/xspace/`. The name
`xspace` is retained for compatibility with existing checkpoints.
